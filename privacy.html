Privacy policy

Last updated: 22 October 2026

This policy covers the Unsupervised Machines uploader, a private tool used only by the owner of the Unsupervised Machines YouTube channel.

What the uploader does

  • Uploads the channel's own finished videos, thumbnails and captions to the owner's own YouTube channel (YouTube Data API).
  • Saves small review copies of those videos to a folder in the owner's own Google Drive, and only touches files it created itself (Google Drive API, drive.file).

What data it uses

It uses the owner's Google sign-in only to perform the uploads above. It does not collect, store, sell or share any personal data, and it does not access other people's accounts or data. The sign-in token is stored only on the owner's own computer.

The uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube data is also subject to the Google Privacy Policy.

YouTube API Services

The uploader uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

The only YouTube data the uploader handles is the owner's own channel information and the metadata of videos it uploads (title, description, tags, captions, schedule). It stores nothing except the owner's sign-in token on the owner's own computer and a short local log of video IDs it uploaded.

Deleting your data

The sign-in token and the local upload log can be deleted at any time by deleting the files on the owner's computer; nothing is stored anywhere else. Revoking access (below) also invalidates the token immediately. Any data obtained from YouTube API Services is deleted within 30 days of access being revoked.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
